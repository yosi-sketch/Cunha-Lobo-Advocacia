# Advocacia Elder Martins Advogados Associados

Site institucional da Advocacia Elder Martins, com sede em Alfenas, Minas Gerais. Apresenta a equipe, as áreas de atuação informadas pelo escritório e os canais oficiais de contato.

## Desenvolvimento

Instale as dependências com `npm install` e inicie o ambiente local com `npm run dev`.

Abra http://localhost:3000 para visualizar o site.

## Tecnologias

- Next.js 16 com App Router
- React 19
- Tailwind CSS 4
- Framer Motion

As fotografias do escritório ficam em `public/elder-martins`. Metadados e idioma são definidos em `app/layout.tsx`; a identidade de cores do Tailwind 4 está em `app/globals.css`.
