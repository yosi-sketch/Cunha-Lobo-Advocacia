# Cunha & Lobo Advocacia

Site institucional de Direito de Trânsito, com sede em Conselheiro Lafaiete, MG, e atendimento digital em todo o Brasil.

## Desenvolvimento

- Instalar: `npm install`
- Iniciar: `npm run dev`
- Validar: `npm run lint` e `npm run build`

Next.js 16 App Router, React 19, Tailwind CSS 4 e Framer Motion. A arquitetura e os mecanismos de animação do template foram preservados. O tema do Tailwind 4 fica em `app/globals.css`, com `@theme inline`.

## Imagens e identidade

Logo original em `public/cunha-lobo-logo.png`, sem alterações. As três fotografias fornecidas foram convertidas em WebP, com largura máxima de 1200px e sem recortes permanentes: `cunha-lobo-equipe.webp`, `eduarda-retrato.webp` e `vitor-retrato.webp`. As imagens usam `next/image`, tamanhos responsivos, preload da imagem principal e carregamento tardio das demais.

Paleta obtida do logo: dourado claro #f0d0a0 e marfim #fff0d0; dourado intermediário #c5a16b, marrom #795a2c e grafite quente #1c1917 compõem o tema. Cormorant Garamond nos títulos e Plus Jakarta Sans nos textos.
